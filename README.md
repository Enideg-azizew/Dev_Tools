# DevTools - Private Utility Collection

A collection of Python utility scripts for automation, data analysis, media processing, and project management.

## Quick Start

```bash
pip install -r requirements.txt
```

Usage

```bash
python main.py <command> [args...]
```

Commands

Command Description
merge-text Merge text files from directory
watch Watch and sync directories
build Build project from metafile
analyze Run statistical analysis on data
inspect Show project directory structure
pdf Extract text from PDF and read aloud
contacts Generate VCF contact files
audio Generate audio tones and music
encrypt / decrypt Encrypt/decrypt files with password
reset-db Reset Django database and migrations
replace Find and replace strings in files
gen-data Generate sample datasets
db-visual Visualize SQLite database structure
excel Process Excel files
mk-structure Create Django directory structure

Examples

```bash
python main.py analyze data.csv hemoglobin
python main.py encrypt file.txt mypassword
python main.py watch ./src ./dist
python main.py merge-text ./myproject
```
